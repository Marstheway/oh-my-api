Cascade
Connect this gateway to another oh-my-api instance over WSS
{{ template "draft-bar" }}
Role
Hub accepts an outbound WSS connection from a spoke; Spoke dials a hub. The two roles are mutually exclusive.
Hub Configuration
Must be a new provider name. Existing HTTP providers cannot be converted into a hub.
Shared secret used to authenticate the spoke connection.
Cascade providers have no HTTP endpoint and use a WebSocket session. The three inbound protocols are fixed.
Spoke Configuration
Origin only (http/https, host[:port]); no ws(s)://, path, query, fragment, or userinfo.
Shared secret used to authenticate the spoke connection.
Existing provider skipped during cascade jobs to prevent loops.
—
Derived from the hub origin.
Published Models
All public and hidden model groups and redirects are synced to the hub with their names and context length. Internal entries are not published, and hub-side groups/redirects are not auto-created.
